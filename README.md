# Travel & Seyahat Web Sitesi

HTML, CSS ve Bootstrap kullanılarak geliştirdiğim kişisel bir seyahat web sitesi projesidir.

Bu projeyi, öğrendiğim frontend konularını gerçek bir web sitesi üzerinde uygulamak ve HTML, CSS ile Bootstrap konusundaki pratiğimi geliştirmek amacıyla hazırladım. Tasarım sürecinde hazır bir görsel referanstan yararlanırken, sayfanın yapısını ve stillerini kendi ihtiyaçlarıma göre oluşturdum.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Bootstrap 5
- Google Fonts

## Projede Yer Alan Bölümler

- Navbar ve navigasyon menüsü
- Hero / ana banner
- Rezervasyon arama alanı
- Hakkımızda
- Hizmetler
- Popüler destinasyonlar
- Müşteri yorumları
- İstatistikler
- Footer
